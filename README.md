# Mockup Agente IA - DSpace-CRIS

Este proyecto es un **mockup (prototipo de interfaz de usuario)** de un agente de inteligencia artificial diseñado para el **enriquecimiento de metadatos** en un repositorio científico institucional basado en **DSpace-CRIS**.

El objetivo de este proyecto es proveer una visualización ilustrativa a nivel de interfaz de usuario de cómo se vería y funcionaría el agente.

## Despliegue Local

Para desplegar y visualizar este mockup de manera local en tu máquina, sigue las siguientes indicaciones:

### Requisitos previos

Asegúrate de tener instalado [Node.js](https://nodejs.org/) en tu sistema.

### Instrucciones de ejecución

1. **Abre una terminal** en la carpeta raíz del proyecto (`Mockup_Agente_IA`).

2. **Instalar las dependencias:**
   Ejecuta el siguiente comando para descargar e instalar todas las dependencias necesarias del proyecto:
   ```bash
   npm install
   ```

3. **Iniciar el servidor de desarrollo:**
   Una vez instaladas las dependencias, levanta el entorno local ejecutando:
   ```bash
   npm run dev
   ```

4. **Visualizar el Mockup:**
   La terminal te indicará una dirección local (por lo general `http://localhost:5173/`). Haz clic en el enlace o cópialo en tu navegador web para ver la interfaz de usuario del agente en funcionamiento.
